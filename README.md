## Description 📝

This repository, `matlab-codes`, houses a comprehensive set of MATLAB scripts primarily focused on academic coursework and practical implementation of various computational techniques. The codes are categorized into distinct areas:

- **Numerical Analysis:** Covering fundamental numerical methods like Bisection, Fixed Point, Secant, Newton's methods, Gaussian Elimination, and LU Decomposition. It further includes method-wise implementations for Gauss-Seidal, Jacobi, Lagrange Polynomials, Newton Divided Differences, Power Method, Simpsons, and Trapezoidal rules.
- **Optimization Techniques:** Featuring various optimization algorithms such as Algebraic Method, BFS Algebraic Method, Big M method, Dual Simplex Method, Graphical Method, Least Cost Method, and Simplex Method.
- **Signals and Systems:** Demonstrating fundamental concepts like signal generation, analyzing even and odd components of functions, delayed and scaled sine waves, and impulse response calculations using convolution.

The repository serves as a valuable resource for students and practitioners looking to explore and implement these mathematical and engineering concepts in MATLAB.

- **Numerical Analysis:** Solving complex equations that lack analytical solutions, approximating integrals, performing matrix operations, and analyzing system stability.
- **Optimization Techniques:** Finding the best solution for problems with constraints, such as resource allocation, scheduling, and portfolio optimization.
